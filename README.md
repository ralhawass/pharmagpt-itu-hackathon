## What is PharmaGPT?

**PharmaGPT is an AI-powered pharmaceutical development assistant designed to transform complex formulation and drug-development information into structured, evidence-informed insights.**

It combines pharmaceutical domain knowledge, intelligent retrieval, and AI reasoning to support researchers in evaluating development questions more efficiently.
